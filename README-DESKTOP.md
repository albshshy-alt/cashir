# متجر المبيعات — تطبيق الكمبيوتر

تم تحويل الواجهة الأصلية إلى تطبيق سطح مكتب باستخدام Electron، مع الحفاظ على ملفات HTML/CSS/JavaScript والبيانات المحلية داخل المتصفح.

## التشغيل على الكمبيوتر

1. ثبّت Node.js 20 أو أحدث.
2. افتح الطرفية داخل هذا المجلد.
3. نفّذ:

```bash
npm install
npm start
```

يمكن أيضًا استخدام ملف **افتح البرنامج.bat** على Windows بعد تثبيت الاعتماديات.

## إنشاء نسخة Windows

```bash
npm install
npm run dist:win
```

ستظهر الملفات داخل مجلد `release`، وتشمل نسخة محمولة ونسخة تثبيت تلقائي.

## إنشاء نسخة Linux

```bash
npm install
npm run dist:linux
```

## ملاحظات

- البيانات والإعدادات تحفظ محليًا في Local Storage كما في النسخة الأصلية.
- الطباعة تعمل عبر نافذة طباعة النظام.
- لا يحتاج التطبيق إلى اتصال بالإنترنت بعد التثبيت.
- ملفا التشغيل القديمان محفوظان كما هما للتوافق، لكن التشغيل الموصى به هو Electron.
